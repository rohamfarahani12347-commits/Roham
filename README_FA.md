# ROHAM Cluster · پنل ابری و آپلود روی کارت DATA

این پوشه سورس Cloudflare Worker، صفحهٔ ورود و پنل را دارد. فایل‌های داخل ZIP را در ریشهٔ مخزن GitHub قرار دهید. ریشهٔ مخزن باید شامل `wrangler.toml`، `package.json`، `package-lock.json`، پوشهٔ `src` و پوشهٔ `site` باشد.

## اتصال مخزن به Cloudflare

۱. در Cloudflare وارد **Workers & Pages** شوید و یک **Worker** از مخزن GitHub وارد کنید. ریشهٔ پروژه را روی `.` انتخاب کنید.  
۲. دستور Build را `npm ci` و دستور Deploy را `npm run deploy` قرار دهید. برای Build از Node.js 22.12 یا بالاتر استفاده کنید. Wrangler در `wrangler.toml` نام Worker و دو Durable Object موردنیاز را تعریف می‌کند.  
۳. در تنظیمات **Variables and Secrets** همان Worker، دو Secret زمان اجرا را تنظیم کنید.

| نام Secret | مقدار |
| --- | --- |
| `MASTER_TOKEN` | توکن مشترک اتصال MEDIA. همین مقدار را در کد MEDIA وارد کنید. |
| `SITE_PASSWORD` | رمز ورود به پنل ابری. |

نام پیش‌فرض Worker در خط ۱ فایل `wrangler.toml` برابر `roham-os-v4` است. نشانی واقعی Worker را از Cloudflare بردارید و فقط نام میزبان آن را در `CLOUD_HOST` کد MEDIA وارد کنید. برای مثال `roham-os-v4.example.workers.dev`. فرم‌ور MEDIA خودش مسیر `/master` را برای WebSocket اضافه می‌کند.

## فریمور لازم برای آپلود

بستهٔ جداگانهٔ فریمور آپلود دو فایل متنی مستقل دارد.

- `ROHAM_MEDIA_V4_UPLOAD.txt` برای ESP32 مرکزی. مقدار `MASTER_TOKEN` و `CLOUD_HOST` را در بخش `Config.h` داخل فایل تنظیم کنید.
- `ROHAM_DATA_V4_UPLOAD_4MHZ.txt` برای AI Thinker ESP32-CAM رم‌ریدر. سرعت SPI روی ۴ مگاهرتز تنظیم شده است.

برای Arduino IDE، پسوند هر فایل را به `.ino` تغییر دهید و فایل را در پوشه‌ای هم‌نام با اسکچ قرار دهید. محیط آزمون Arduino ESP32 Core 2.0.17، SdFat 2.3.1 و ArduinoJson 6.21.5 بوده است. بستهٔ فریمور تنظیمات خصوصی شبکه را دارد و برای کار روی بردهاست. فایل‌های این مخزن Worker تنظیمات Wi‑Fi بردها را در خود ندارند.

## استفاده از گوشی

۱. صفحهٔ Worker را در مرورگر باز کنید و با رمز سایت وارد شوید.  
۲. در بخش «فایل‌های کارت DATA» فایل را انتخاب کنید و «آپلود روی کارت» را بزنید.  
۳. پس از نمایش تأیید ذخیره، می‌توانید همان فایل را از فهرست دانلود کنید.

انواع فایل تا ۸ مگابایت برای هر فایل پذیرفته می‌شوند. نام اصلی فایل در فهرست و دانلود، از جمله برای نام‌های فارسی، حفظ می‌شود. روی کارت، فایل‌ها با نام‌های یکتا در پوشهٔ `/uploads` ذخیره می‌شوند و عکس‌های گرفته‌شده از دوربین در گالری جداگانهٔ `/photos` می‌مانند. نتیجهٔ موفق پس از تأیید بستن فایل و تغییر نام فایل موقت از سمت DATA به مرورگر فرستاده می‌شود.

## بررسی

فرم فایل، ورود، دانلود و حفظ نام فارسی در Chromium با اندازهٔ صفحهٔ موبایل آزموده شدند. Worker و Durable Object در Wrangler محلی با MEDIA شبیه‌سازی‌شده اجرا شدند. نوشتن فایل، دریافت بایت‌به‌بایت و پاک‌سازی پس از قطع انتقال با منطق واقعی فریمور روی تصاویر FAT32 و exFAT بررسی شدند. آزمون این نسخه روی برد فیزیکی و استقرار آن روی حساب Cloudflare انجام نشده است.
