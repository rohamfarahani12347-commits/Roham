# راهنمای دیتاسنتر ROHAM

## ساختار مخزن

هفت فایل در ریشهٔ مخزن و فایل بررسی خودکار در پوشهٔ `.github/workflows` قرار می‌گیرند. `worker.js` صفحهٔ ورود و پنل فایل‌ها را همراه با کد Cloudflare در خودش دارد. هر دو فایل `wrangler.jsonc` و `wrangler.toml` به همین ورودی اشاره می‌کنند.

## راه‌اندازی روی Cloudflare

۱. محتویات ZIP را در ریشهٔ مخزن GitHub قرار دهید و مخزن را در بخش Workers & Pages به Worker وصل کنید.  
۲. برای Build از Node.js 22.12 یا بالاتر استفاده کنید. دستور Build را `npm ci` و دستور Deploy را `npm run deploy -- --config wrangler.jsonc` قرار دهید.  
۳. نام Worker در بسته `roham-os-v4` است. اگر نام پروژهٔ مستقر متفاوت است، مقدار `name` را در هر دو فایل تنظیمات با نام پروژهٔ خود هماهنگ کنید.  
۴. در Variables and Secrets همان Worker دو Secret زمان اجرا را تنظیم کنید. `SITE_PASSWORD` رمز ورود است و `MASTER_TOKEN` باید با مقدار کد MEDIA یکسان باشد.

Workflow این بسته با هر تغییر، ساخت آزمایشی Worker را بررسی می‌کند. انتشار سایت از اتصال مخزن به Cloudflare انجام می‌شود.

## استفاده از سایت

- بعد از ورود با رمز سایت، وضعیت ارتباط DATA و آماده بودن کارت را بالای پنل می‌بینید.
- در بخش «آپلود روی کارت» می‌توانید از گوشی یا رایانه فایل انتخاب کنید. سقف هر فایل ۸ مگابایت است.
- فایل‌های ذخیره‌شده در فهرست سمت دیگر پنل ظاهر می‌شوند. جست‌وجو در صفحهٔ فعلی انجام می‌شود و با دکمه‌های صفحهٔ قبل و بعد می‌توانید بقیهٔ فایل‌ها را ببینید.
- فایل‌ها در پوشهٔ `/uploads` روی کارت DATA ذخیره می‌شوند و نام اصلی آن‌ها در فهرست و دانلود حفظ می‌شود.

این Worker با فریمور آپلود MEDIA و DATA که قبلاً تحویل داده شد ارتباط می‌گیرد. اگر نشانی Worker عوض شد، `CLOUD_HOST` در MEDIA باید همان نام میزبان جدید باشد.
